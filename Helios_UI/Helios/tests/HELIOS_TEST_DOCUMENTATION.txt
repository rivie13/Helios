System Overview
Helios is a multi-robot simulation control system that allows users to configure, start, and monitor robot simulations in different disaster scenarios such as wildfires, earthquakes, and floods. The application provides a unified interface for controlling these simulations, collecting data from robot sensors, and generating reports on simulation performance.

The system uses a client-server architecture where the main Helios UI application (written in Python with PyQt5) acts as a control center that communicates with simulation environments via socket connections. The application can embed Unity-based simulations within its interface and exchange data through TCP/IP sockets, allowing for real-time monitoring and control of robot activities.

Key components of the Helios system include:

1. Main Application Window: Provides the central control interface with tabbed views for simulation control, sensor monitoring, and data visualization.

2. Socket Communication: Enables bidirectional data exchange between the Helios UI and simulation environments.

3. Simulation Control: Allows users to start, pause, and stop simulations, as well as select different simulation types.

4. Sensor Data Monitoring: Displays real-time data from robot sensors including temperature, humidity, battery level, and position coordinates.

5. Data Collection and Reporting: Records simulation metrics including resolution time and success rate, with options to export data in CSV format or generate PDF reports.

The Helios application also features a modern, customized UI with a custom title bar, specialized dashboard widgets, and sensor data displays that update in real-time as the simulation runs.

This testing document outlines the comprehensive test procedures for verifying that all aspects of the Helios application function correctly, from individual components to end-to-end workflows.
